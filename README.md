# Rig Bench（pedal-sim）

ギター・エフェクター・アンプの組み合わせから、どんな音が出るかを画面上でシミュレーションするツールです。
つまみを回すと、周波数特性・ゲインステージ・倍音・時間変化のグラフと、電源の計算がその場で変わります。

いまは **画面と計算の土台（試作）** の段階です。数値の多くは暫定で、画面の「読み取り元」に確認状況を表示しています。

## 動かし方

HTML・CSS・JavaScript だけで動きます。インストールやビルドは要りません。

```sh
# どちらか
open index.html                # ブラウザで直接開く
python3 -m http.server 8000    # http://localhost:8000 を開く
```

計算部分のテスト（Node.js 18 以降）:

```sh
npm test
```

## 画面の構成

ツールバーの「編集 / 比較 / シート」で切り替えます。

### 編集

| 場所 | 内容 |
|---|---|
| 上段（信号の流れ） | 実際の接続順に機材を並べる。小さいつまみはそのまま回せる。下の ON/OFF ボタンで切り替え |
| 左（解析） | 周波数特性（参考音源との差つき）、ゲインステージ、倍音、時間変化、測定値 |
| 右（インスペクタ） | 「機材」タブ：選んだ機材のつまみ・計算値・解析方法・読み取り元。「電源」タブ：パワーサプライの割り当て |

### パッチ

- ツールバーで切り替え・名前の変更・複製・削除ができます（削除は 2 回押し）
- 変更はこのブラウザに自動保存されます（別のブラウザや端末には引き継がれません）
- 最初に入っている 3 つのパッチは例です

### 比較

最大 4 つのパッチを選んで重ねて比べます。

- 周波数特性・ゲインステージ・時間変化を色分けで重ね表示
- 測定値（THD、クリップ量、余韻、参考音源との差など）を横並び
- 設定の表：パッチ間で違う行に縦線。「違いのある行だけ表示」で絞り込み
- 列見出しの「編集」でそのパッチを開く

### シート

ローディーや PA に渡すセッティングシートです。

- 「1 パッチ 1 ページ」：つまみを時計の向きの図で表示。OFF の機材は破線。メモ欄・周波数特性・電源表つき
- 「一覧表」：選んだパッチを横に並べた表（違う行に縦線）
- 日付・会場・担当は入力でき、全ページに反映
- 「印刷 / PDF に保存」で A4 縦に出力（ブラウザの印刷画面で「PDF に保存」を選ぶ）
- RETURN 接続のアンプは、音に関係しないプリ部のつまみを載せない

### キーボード操作

| キー | 動作 |
|---|---|
| `[` `]` | 機材を選ぶ |
| `B` | 選んだ機材の ON/OFF |
| `↑` `↓` | つまみ ±0.25（`Shift` で ±1）。ドラッグ中の `Shift` は微調整 |
| `R` | 参考音源の重ね表示 |
| `E` | 使用環境（リハスタ / ライブハウス / レコーディング） |
| `P` | 電源タブ |

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（色・文字はすべてここのトークンで管理） |
| `js/engine.js` | 計算（周波数特性・クリップ・倍音・時間変化）。DOM に依存しない |
| `js/data.js` | 機材データ（ギター・アンプ・エフェクター・電源・出典と確認状況） |
| `js/app.js` | 状態管理と操作（つまみ・キーボード） |
| `js/view.js` | 描画（グラフ・信号の流れ・インスペクタ・電源表） |
| `js/patch.js` | パッチの保存・切り替え・複製・削除（ブラウザに自動保存） |
| `js/compare.js` | 比較画面とセッティングシート（印刷用のスタイルは `css/style.css` の末尾） |
| `js/main.js` | 起動処理 |
| `docs/decisions.md` | これまでの議論で決めたこと |
| `tests/` | 計算部分のテスト |
